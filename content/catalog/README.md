# Freshwater reference catalog

This catalog is independent of illustrative aquarium fixtures and 3D assets. It adds four river references and eight freshwater taxa; it does not add new underwater habitats or assert occurrence for the polar-parrot study.

Each association has its own locality, evidence period, citation and native-status determination. `basinEndemic: false` means no basin-endemic claim is made. `uncertain` means occurrence is supported but basin-native status is unresolved. Species names follow the cited sources, not a claim of a complete current taxonomic revision. Alternate common/river names are search aids; scientific synonyms require a taxonomic source before adding them. No conservation category or aquarium parameters are inferred.

Sources were reviewed on 23 October 2026. DOI links identify the primary papers; the ICAR-CIFRI page is an institutional project source with no publication date stated. Survey dates describe historical evidence, not a fresh observation. Sensitive localities remain at sanctuary, regional or sub-basin level.

The Cauvery paper explicitly marks Rohu, Catla and Mrigal among introduced fishes. Do not copy their Gangetic native status into other basin associations. The Godavari Badis record supports occurrence in Manjeera and Wardha streams, not ubiquitous main-channel occurrence or proof of native origin. The Krishna record does not establish basin endemism.

Deferred: Brahmaputra records and Catla/Mrigal nomenclature need further accessible taxonomic verification. The existing multi-species aquarium PR #1 concerns rendering and fixtures; this catalog deliberately does not change those files or import ornamental colour variants as native taxa.

Run `npm test -- src/lib/catalog.test.ts` for catalog integrity checks. Review citations and ecological scope as well as automated validation when expanding this file.
